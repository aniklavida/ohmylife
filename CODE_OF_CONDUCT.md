# Code of conduct

Be respectful, specific and constructive. Harassment, discrimination, threats, doxxing and deliberately disruptive behaviour are not accepted.

This project is about people's private lives. Treat any example, screenshot or bug report that contains someone's real data with the care you would want for your own — and redact before you post.

Before the v1.0 release this will be replaced by an established community code of conduct with a private enforcement contact.
